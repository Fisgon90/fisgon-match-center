# Fisgon Match Center (FMC)

**A hybrid esports broadcast management system for VALORANT.**

Fisgon Match Center (FMC) is a customizable broadcast overlay designed to manage and display two simultaneous VALORANT matches through a centralized control panel.

The project combines automated match data integration with manual controls, giving broadcasters flexibility and reliability during live productions.

## Key Features

- **Dual Match Display:** Show two matches simultaneously.
- **Main Match Mode:** Highlight a selected match.
- **Centralized Control Panel:** Manage match visibility and broadcast layouts.
- **Hybrid Data System:** Combine automated data retrieval with manual overrides.
- **Match Information:** Display teams, logos, scores, maps, and match status.
- **OBS Integration:** Designed for browser-based broadcasting through OBS and StreamElements.

## Project Architecture

FMC is being developed around five main components:

1. Control Center
2. Data Engine
3. API Integration
4. State Management
5. Broadcast HUD
